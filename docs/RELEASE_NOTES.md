# 0.1.0-alpha.3

Windows Jev 决策与 Computer Use 适配实验的首个 GitHub alpha 发布。当前包含 trycua 的 UIA、浏览器语义状态和截图统一观察封装，以及有界计算器和网页任务；官方 CU 执行适配只完成过计算器样本验证。

本版补齐离线 CI、隔离源码包复验、按主分支精确提交发布、发布后下载校验和维护问题回流。通用 SDLC 宿主工具独立于产品；普通安装、测试和使用无需采用维护者的流程。项目自己的计划与审查记录随代码保存。代码审查由编写代码的宿主自查，没有声称独立审查或通用电脑操作稳定性。

发布包仅含源码。Node.js、Python、trycua driver、API key 和官方运行时需自行准备；供应商二进制、截图、密钥与个人浏览器资料不包含在内。安装与使用见 README；来源归属见 PROVENANCE 和 THIRD_PARTY_NOTICES。各上游成果与服务保持其原有权利，项目没有官方合作或背书。
